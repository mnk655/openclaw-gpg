プライバシーポリシー

最終更新日: 2026-11-24

1. 対象

本ポリシーは、個人利用のツール「openclaw-gpg」(以下「本アプリ」)が Google アカウントのデータをどのように扱うかを説明するものです。本アプリは開発者本人のみが利用し、他のユーザーに提供していません。

2. 取得するデータ

本アプリは、開発者自身の Google アカウントについて、次の読み取り専用の権限のみを要求します。

  • Gmail の読み取り (gmail.readonly)
  • Google カレンダーの読み取り (calendar.readonly)
  • メールアドレスの確認 (userinfo.email、openid)

メールの送信・削除、予定の作成・変更など、データを書き換える操作は行いません。

3. データの利用目的

取得したメールおよび予定の内容は、開発者本人が自分の予定やメールを確認するためだけに使用します。広告、マーケティング、データの販売、人工知能モデルの学習のための利用は行いません。

4. 保存と共有

  • 認証情報(リフレッシュトークン)は、開発者が管理するサーバ内にのみ保存されます。
  • メールおよび予定の内容は、開発者が管理するサーバ内で処理され、第三者に提供・販売・公開されることはありません。
  • 法令に基づく場合を除き、第三者への開示は行いません。

5. データの削除

認証情報は、開発者がいつでも削除できます。また、Google アカウントの「サードパーティによるアクセス」から、本アプリのアクセス権を取り消せます。

6. Google API サービスのユーザーデータに関するポリシー

本アプリによる Google API から受け取った情報の使用および他のアプリへの移転は、Google API サービスのユーザーデータに関するポリシー(限定的な使用の要件を含む)に準拠します。

7. 連絡先

Privacy Policy

Last updated: 2026-11-24

1. Scope

This policy explains how the personal tool "openclaw-gpg" (the "App") handles Google account data. The App is used only by its developer and is not offered to other users.

2. Data accessed

For the developer's own Google account, the App requests only the following read-only permissions:

  • Read Gmail (gmail.readonly)
  • Read Google Calendar (calendar.readonly)
  • Confirm the email address (userinfo.email, openid)

The App does not send or delete email, or create or modify calendar events.

3. How the data is used

Email and calendar content is used only so that the developer can review their own schedule and messages. It is not used for advertising, marketing, sale of data, or training artificial intelligence models.

4. Storage and sharing

  • Credentials (refresh tokens) are stored only on a server controlled by the developer.
  • Email and calendar content is processed on that server and is not provided, sold, or published to any third party.
  • Data is not disclosed to third parties except where required by law.

5. Deletion

The developer can delete the stored credentials at any time, and can revoke the App's access from the "Third-party access" page of the Google Account.

6. Google API Services User Data Policy

The App's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
